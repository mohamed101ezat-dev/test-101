# كود البرنامج مقسّم

- **اكتب التعديلات هنا في `src/js/`**، مش في `js/app.js`.
- بعد أي تعديل: `node build.js` ← بيجمّع الملفات بالترتيب (01، 02، …) في `js/app.js` اللي بيشتغل على الموبايل.
- الترتيب مهم: الملفات بتتجمّع ورا بعض كأنها ملف واحد.

| الملف | فيه إيه |
|---|---|
| 01-core | البداية، رقم النسخة، مكان الحفظ |
| 02-balance | حساب رصيد العميل |
| 03-storage-sync | التخزين والمزامنة |
| 04-confirm-tabs | تأكيد بضغطتين، الاسترجاع، التابات |
| 05-invoice-image-pdf | رسم صورة الفاتورة، تصميمها، PDF والطباعة |
| 06-orders | متابعة الطلبيات |
| 07-customers | العملاء والفئات |
| 08-items | الأصناف |
| 09-invoice | شاشة الفاتورة والدفع والحفظ |
| 10-quotes-whatsapp | عروض الأسعار وواتساب |
| 11-backup | النسخة الاحتياطية والسحابية |
| 12-cloud-account | الحساب والمزامنة السحابية |
| 13-pwa | تطبيق الموبايل |
| 14-settings | الإعدادات |
| 15-expenses | المصروفات |
| 16-suppliers | الموردين |
| 17-stock | المخزن |
| 18-alerts-start-import | التنبيهات، البداية، الاستيراد والتصدير |
| 19-log-reports | السجل والتقارير |
| 20-reminders | تذكير المديونين |
| 21-auto-close | الإقفال التلقائي |
| 22-calc-lock | الحاسبة والقفل والرقم السري |
| 23-auto-backup | النسخ التلقائية |
| 24-boot-back | التشغيل وزرار الرجوع |
